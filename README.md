## Features
- Quick shortcuts at the bottom of the page. 4-8 shortcuts per row.
- Use your preferred image as background.
- Follows system light/dark mode.
- No information is collected, every settings are stored in the device.
- Entire page and settings are saved in local, so it's accessible even when the device is offline.
<br>
<br>

## How to use
Set https://alternative415.github.io/ as your homepage in browsers.
